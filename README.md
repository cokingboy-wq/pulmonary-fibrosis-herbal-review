# Pulmonary Fibrosis Herbal Medicine Systematic Review

Systematic review project evaluating nine individual Chinese herbal medicines for pulmonary fibrosis.

## Project Objectives

- Conduct reproducible literature searches.
- Preserve original PubMed search results.
- Document frozen search strategies and search logs.
- Support literature screening and evidence synthesis.
- Maintain version-controlled research materials.
